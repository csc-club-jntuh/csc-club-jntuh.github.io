# Cybersecurity Club — JNTUHCEH 🛡️

Official community portal and verified link directory for the **Cybersecurity Club** at Jawaharlal Nehru Technological University Hyderabad College of Engineering (JNTUHCEH).

🔗 **Live Portal**: [https://csc-club-jntuh.github.io](https://csc-club-jntuh.github.io)

---

## 🚀 Features

- **Centralized Community Links**: Verified links for WhatsApp Community, GitHub Organization, LinkedIn Page, YouTube Channel, and Instagram.
- **Cyber Aesthetic & Responsive Design**: Seamless layout across mobile (320px+), tablet, and desktop devices.
- **Dark & Light Mode**: Persistent theme switcher with OS color-scheme auto-detection and mobile browser status-bar tinting.
- **Interactive Share Portal**: Scannable QR code resolving directly to the portal, one-click link copying, instant social share channels (WhatsApp, Telegram, LinkedIn, X), and native device share sheet integration.
- **WCAG 2.2 Accessibility**: High-contrast ratios, keyboard focus indicators, skip-to-content navigation, and `prefers-reduced-motion` compliance.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler & Tooling**: [Vite 8](https://vite.dev/)
- **Linter**: [Oxlint](https://oxc.rs/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) via GitHub Actions

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/csc-club-jntuh/csc-club-jntuh.github.io.git
cd csc-club-jntuh.github.io
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
